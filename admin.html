🕌 புதிய பயான் பதிவேற்றம்

இந்தப் பக்கத்தின் மூலம் புதிய பயான் உங்கள் GitHub repository-ல் சேமிக்கப்படும். சேமித்த பிறகு பொது இணையதளத்தில் காட்டப்படும்.

பாதுகாப்பு: GitHub Token-ஐ இந்தப் பக்கத்தில் நிரந்தரமாகச் சேமிக்கவில்லை. ஒவ்வொரு முறையும் நீங்கள் உள்ளிட வேண்டும். யாரிடமும் Token-ஐ பகிர வேண்டாம். Fine-grained token-ல் இந்த repository-க்கு மட்டும் Contents: Read and write அனுமதி கொடுக்கவும்.
Token இந்தப் பக்கத்தில் சேமிக்கப்படாது; பக்கத்தை மூடும்போது நினைவகத்திலிருந்து அழிக்கப்படும்.
நிலையான பதிவேற்றத்திற்காக 20 MB-க்குள் உள்ள ஆடியோவைத் தேர்வு செய்யவும்.
பதிவேற்றத் தயாராக உள்ளது.
